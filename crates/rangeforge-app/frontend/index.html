        DSD Format

        DSD files cannot be written as they are. They are written in the Output Format you chose (codec, container, bitrate, compression, channels and downmix). Only these two are kept here: the sample rate and bit depth to use where the Output Format says source. Each is used on its own, and an Output Format that names one keeps it. These apply as soon as you change them.

        Before changing files

        API keys

        Keys are kept in this computer's own credential store, not in a file. Each can be switched off without forgetting it. The Metadata API switch on the main screen must be on too.

        RangeForge does not come with a Last.fm key. Getting your own is free: create one for an app on Last.fm, then paste it here. The key stays on this computer.

        Last.fm answers are kept for weeks so they are not asked twice. Clear them to pull every genre fresh.

        RangeForge

        Measures loudness once, evens out volume with one gain per song, splits CUE albums, tags and writes clean files. Free to use.

        If it saves you time, you can support it on Ko-fi. It is optional and nothing is locked behind it.

        Several tags can be pasted at once, separated by commas, semicolons or line breaks.

        A box left empty keeps what each song has. These names also go on the written files, over what a CUE sheet says (the sheet's split points and track numbers stay).
