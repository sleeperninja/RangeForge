# 02 - UI

The mockups in [mockups/](mockups/) are the source of truth. This page describes them in words. If they disagree, the mockups win and this page gets fixed.

## Layout, top to bottom

1. **Title bar.** Custom dark bar with the app name and window buttons.
2. **File table (most of the window).** The whole window accepts file drops. The table scrolls.
3. **Control strip (bottom).** Run controls, output format, presets, volume, and file strategy, left to right.
4. **Log panel (optional, right).** Opens with the **Show Logs** toggle. Scrolls independently.

## The file table

| Column | Meaning |
| --- | --- |
| Name | Album rows are parents. Tracks sit indented beneath with a small arrow. |
| Codec | On an album row: `Split(cue)` for a CUE album. On a single file: the **source** codec in brackets, like `(flac)`. On a track row: the **output** codec. |
| Loudness (LUFS) | Measured integrated loudness. |
| True Peak (dBTP) | Measured true peak. |
| Adjust (LUFS) | Gain that would be applied to reach the target. |
| Range | Loudness range. See decision D-04 on the DR/LRA naming. |
| Tags | Genre tags, comma separated, colour coded (below). |

A row that has not finished measuring shows `-` in the measurement columns and fills in when ready.

### Tag colours

- **Plain text:** album-level tags (for example Classic Rock, Hard Rock).
- **Blue:** the **Radio** tag, meaning the song charted on the Billboard Hot 100.
- **Pink/red:** song-level tags that differ from the album (for example Funk Rock, Synthpop).

## Control strip

**Run block**
- **Run (N):** processes N queued files. N is the selected count, or all if none are selected.
- **Auto Mode:** toggle. Starts a run automatically once analysis finishes. *(Behaviour to confirm.)*
- **Metadata API:** toggle for online tag lookups.
- **Show Logs:** toggle for the log panel.
- **Settings:** opens the Settings dialog.

**Output Format**
Codec, Container, Sample Rate, Bit Depth, Channels. Any can be set to keep the original.

**Format Presets**
A list (iTunes Lossy, iTunes Lossless, CD Quality, Flac HD Multi, ALAC Multi) with **Delete Preset** and **Save Preset**. Picking one fills Output Format and, where stored, volume settings. Save Preset is disabled until something differs from the selected preset.

**Volume Adjustment**
- **Target Loudness** in LUFS (mockup default -22).
- **Peak Protection** checkbox plus a dBTP ceiling (mockup default -0.6). When on, gain is capped so the true peak never goes above the ceiling.

**File Strategy** (choose one)
- **Serialize new filename:** adds a suffix such as `_00`.
- **Rename old file:** renames the original with a suffix such as `_old`, then writes the new file under the original name.
- **Replace original:** overwrites. The mockup selects this one.
- **Save to location:** writes to a chosen folder. Has a Browse button.

## Settings dialog

- **API Keys:** Last.fm and Discogs. Stored encrypted.
- **CPU:** thread limit. Auto, or a fixed number (the machine's maximum is shown).
- **DSD Format:** the output used when the input is DSD (codec, container, sample rate, bit depth, channels), with **Keep Original**.
- **Close** button.

## Resizing

From mockups 4 and 5 (taller window):

- **File table:** takes all spare height. It scrolls when rows overflow, which is the `[scrolls]` marker in the mockups.
- **Control strip:** keeps its height and stays anchored to the bottom of the window.
- **Log panel:** runs the full window height beside both the table and the control strip, and scrolls on its own.
- **Opening the log panel:** in mockup 3 the window is wider (1728 px against 1440 px), so the panel appears to add width and the table keeps its size. *(Behaviour on a window that cannot grow, such as a narrow screen, is not yet specified.)*

## Behaviours worth stating

- Analysis results appear as they complete, per file.
- Changing Target Loudness or Peak Protection updates the Adjust column immediately. No re-analysis happens.
- Nothing is written to disk until Run.
- Log lines are timestamped and describe each step (added file, cue detected, split, lookup results, loudness scan).
